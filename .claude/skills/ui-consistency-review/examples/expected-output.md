## ケース1: 複数の不一致を検出

### 状況
- タスク一覧画面のアクションバー改修前に実行
- `components/` 配下に `todo-action-bar.tsx` / `todo-bulk-update-dialog.tsx` / `todo-search-bar.tsx` がある

### 出力

```
## UI Consistency Review

### 現状の評価

#### カラーパレット
- 使用色:
  - テキスト: `text-stone-700`, `text-gray-500`, `text-orange-500`
  - 背景: `bg-orange-50`, `bg-white`
  - ボーダー: `border-orange-200`, `border-stone-200`
  - アクセント: `text-orange-400`
- 気になる点: テキストカラーに `text-stone-700` と `text-gray-500` が混在している。補助テキストの役割に対して2種類の色が使われており、統一が必要。

#### スペーシングリズム
- 使用余白: `mb-4`, `mb-6`, `gap-2`, `gap-3`, `px-4`, `py-3`, `p-4`
- 気になる点: カード間の `mb-` が `mb-4` と `mb-6` で混在。視覚的なリズムが不規則になっている。

#### タイポグラフィ階層
- 使用スタイル: `text-xl font-bold`, `text-base`, `text-sm`
- 気になる点: `todo-search-bar.tsx` の説明テキストに `text-sm` が使われているが、ユーザーが能動的に読む内容のため `text-base` が適切。

#### 視覚的重みのバランス
- 気になる点: `todo-bulk-update-dialog.tsx` の件数表示が `text-xl` で、アクションバーの見出しと同じサイズになっている。件数が主役かアクションが主役か階層が不明確。

#### インタラクション
- 気になる点: `todo-action-bar.tsx` は `hover:opacity-80`、`todo-bulk-update-dialog.tsx` は `hover:bg-orange-100` と表現が統一されていない。

### 修正提案（優先度順）

1. 補助テキストのカラーを `text-stone-500` に統一する（`text-gray-500` → `text-stone-500`）
2. カード間余白を `mb-4` に統一する（`mb-6` → `mb-4`）
3. `todo-search-bar.tsx` の説明テキストを `text-sm` → `text-base` に変更する

→ 上記を踏まえた上で変更を進めます。
```

## ケース3: 複雑な判断を含む提案（NG→OK書き換え）

### 状況
- 既存のタグ選択パーツ（選択中はオレンジ、それ以外は青で表示する複数選択 UI）を、別画面で流用しようとしている
- 新しい画面ではステータスを1つしか選ばないため、青色の意味がなくなる

### NG例（専門用語が多く、結論が埋もれている）

```
TagPicker の非選択時の青はコンポーネント内部にハードコードされており、
そのまま流用すると status-select に青が混入する。タグ選択画面では「複数タグの
選択/非選択」を区別する目的で青が使われているが、ステータス選択は常に1つしか選ばないため
非選択状態の表示自体が不要になる可能性がある。
```

### OK例（平易・一文一意・結論が先）

```
このまま使うと、意味のない青色が画面に出てきてしまう。
理由: 元の部品は「選んでいるタグはオレンジ、まだ選んでいない他のタグは青」で
色分けする作りだが、新しい画面はステータスを1つしか選ばないので、青色を出す意味がない。
対応案: オレンジ1色だけで選択中のステータスを示す、シンプルな見た目に作り直す。
```
